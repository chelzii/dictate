# 后续路线图

本轮：目录分离、模块边界、安装诊断、代码切换回退、统一检查入口、发布产物、CI、MIT 和贡献说明。

后续按可验收范围逐步推进：

1. 全新 Ubuntu X11 虚拟机的完整安装矩阵；实际版本支持范围逐步记录。
2. 配置 schema 与消息协议版本化，扩展状态机的取消/超时竞争测试。
3. 固定扩展身份和更便捷的分发渠道；当前 unpacked 路径变更仍需重新确认 ID。
4. 更新回退命令和旧 releases 清理策略；当前保留安装历史，不自动下载更新。
5. 稳定的会话服务管理与崩溃恢复；当前沿用已验收的桌面自启动。
6. ChatGPT 页面变化检测及适配测试。

Wayland、终端粘贴策略和其他操作系统属于独立功能，不纳入本轮目录重构的兼容承诺。
