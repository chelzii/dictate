## 取消转写的迟到结果

旧正式扩展的真实桌面流程已复现：F8 取消不插入，但后续 F9 被后台草稿保护拦住。根因是 abort 只清理扩展会话，没有隔离尚在返回结果的转写文档。

修复后的隔离 Chrome 回归通过：取消转写后旧页移除、目标不插入、下一次后台建页并正常完成；录音取消仍复用原页；用户手动编辑的草稿保留但解绑；空闲 F8 可恢复旧草稿阻塞。正式扩展的新一轮真实测试需要 Chrome 重新加载新代码，结果以实际验收补记为准。
